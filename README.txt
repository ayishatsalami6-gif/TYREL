PAN VIDEO MAKER — PHONE-ONLY PWA STARTER

Files:
- index.html: your existing editor, prepared as the app's main page
- manifest.webmanifest: app name, icon, and standalone display settings
- sw.js: basic offline caching for the app shell
- icons/: app icons

IMPORTANT:
This is a PWA-ready website bundle, NOT an APK yet. It must be hosted on HTTPS before a service like PWABuilder can package it. Video export and saving must be tested on your Android device after packaging; browser/WebView behavior can differ.
